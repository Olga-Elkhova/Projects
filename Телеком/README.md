# Анализ активности клиентов оператора сотовой связи.
## Цели проекта: 
- проанализировать текущие тарифные планы компании и активность клиентов
- оценить долю клиентов, которые пользуются услугами сверх тарифного плана.
  
Это позволит обновить линейку тарифных планов под запросы клиентов, а также разработать систему специальных предложений для самых активных клиентов.

## Описание компании: 
В базовый пакет услуг компании входят телефонные звонки, интернет-трафик и сообщения. Оператор предлагает клиентам два тарифных плана: Smart и Ultra. Они различаются ежемесячным платежом и пакетом включённых услуг.

Различается и стоимость услуг сверх тарифного плана:

Счёт выставляется клиенту в начале каждого календарного месяца. Объём услуг, то есть длительность разговоров, объём интернет-трафика и количество сообщений, считается за полный календарный месяц для каждого клиента. При этом длительность звонков округляется вверх.

## Содержание:

1. Создание витрины с агрегированными данными по месяцам. Файл telecom.sql

2. Расчет трат клиентов сверх тарифа с разбивкой по тарифам.
