# Анализ активности клиентов оператора сотовой связи.
## Цели проекта: 
- Проанализировать текущие тарифные планы компании и активность клиентов
- Оценить долю клиентов, которые пользуются услугами сверх тарифного плана.
  
Это позволит обновить линейку тарифных планов под запросы клиентов, а также разработать систему специальных предложений для самых активных клиентов.

[telecom](https://github.com/Olga-Elkhova/Portfolio/blob/main/%D0%A2%D0%B5%D0%BB%D0%B5%D0%BA%D0%BE%D0%BC/telecom.sql)

## Описание компании: 
В базовый пакет услуг компании входят телефонные звонки, интернет-трафик и сообщения. Оператор предлагает клиентам два тарифных плана. 
Они различаются ежемесячным платежом и пакетом включённых услуг.
Различается и стоимость услуг сверх тарифного плана:

Счёт выставляется клиенту в начале каждого календарного месяца. Объём услуг, то есть длительность разговоров, объём интернет-трафика и количество сообщений, считается за полный календарный месяц для каждого клиента.

## Содержание:

**1.** Создание витрины с агрегированными данными по месяцам.
   
- Данные клиентов с информацией о ежемесячных объёмах услуг (суммарная длительность звонков, объём интернет-трафика, количество сообщений) и текущие траты клиентов согласно тарифным планам.
  
- Среднее значение трат клиентов на услуги связи для каждого тарифного плана. Только те клиенты, которые продолжают пользоваться услугами компании.
  
- Клиенты, которые пользуются услугами сверх тарифа, их средние расходы и среднее значение переплаты для каждого тарифа.
   
**2.** Расчет трат клиентов сверх тарифа с разбивкой по тарифам.

- Данные клиентов с информацией о ежемесячных объёмах услуг (суммарная длительность звонков, объём интернет-трафика, количество сообщений) и текущие траты клиентов — согласно тарифным планам.
  
- Рассчет среднего значения трат клиентов на услуги связи для каждого тарифного плана. Только те клиенты, которые продолжают пользоваться услугами компании.
  
- Клиенты, которые пользуются услугами сверх тарифа, их средние расходы и среднее значение переплаты для каждого тарифа.
